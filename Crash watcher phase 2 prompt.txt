Below 2.00.

YELLOW:
10.00 and above.

Use OCR and image processing together.

Requirements:

- Image preprocessing.
- Contrast enhancement.
- Appropriate thresholding.
- Color sampling.
- Text normalization.

- Multiplier parsing.

5. Round Detection

This is extremely important.

The game displays changing information during a round.

The application must distinguish:

- Previous round result.
- Current round animation.
- New round.
- Final completed multiplier.

A changing animation value must never be registered as a completed round.

Implement a state machine for visual round detection.

Possible states:

WAITING
ROUND_IN_PROGRESS
RESULT_CANDIDATE
RESULT_CONFIRMED
UNCERTAIN

A multiplier must be stable and visually confirmed before being emitted as a completed result.

Use configurable stability requirements and frame comparisons.

The engine must not emit the same completed result repeatedly.

Do not assume that the previous multiplier remaining visible means a new round has completed.

If the system cannot distinguish a previous result from a new result, mark it uncertain rather than creating a false round.

6. Timing
